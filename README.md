# pyoxygen
This program interprets Oxygen programs.

## How to Use
To use pyoxygen on a file:
```
python3 src/main.py <program_path>
```

For example:
```
python3 src/main.py tests/test.oxy
```

You will need microASM (found [here](https://github.com/the-coder256/microASM)) and microVM (found [here](https://github.com/the-coder256/microVM)) to run the generated bytecode.
